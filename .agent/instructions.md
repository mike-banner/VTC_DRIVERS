## 🛠️ CODING STANDARD (FILES & PATHS)
Every code block must include the file path on the very first line, immediately following the language tag.

- **PHP**: `<?php // path/to/file.php`
- **JS/TS**: `// path/to/file.ts`
- **Python**: `# path/to/file.py`
- **HTML**: `<!-- path/to/file.html -->`
- **CSS/SASS**: `/* path/to/file.css */`

3. **Call to Correction**: Propose the "Senior" alternative immediately.
